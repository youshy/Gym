# v7 Cheat Sheet — the whole week, every set written out

Built on v6 ([`../v6/2026-07-26-workout-plan.md`](../v6/2026-07-26-workout-plan.md)): athletic power + plyometrics first, pullup Grease the Groove, chest / triceps size — plus **more biceps**, **no running** (15 minutes easy stair stepper instead). Every lifted set below has its weight and reps written out; explosive / plyometric work is tracked outside the programme and is listed by movement only.

**Training Maxes (90% of estimated one-rep max):** Squat **115** · Bench Press **95** · Deadlift **115** · Overhead Press assumed max **42.5** (working weight 35–37.5, see below). Every weight rounds **down** to a loadable plate.

**v7.1 (2026-10-02):** rebalanced so every lift day fits **60 minutes** (+15 minutes stair stepper) — dips moved right after Saturday bench, Overhead Press moved Saturday → Thursday, hanging leg raise moved to Saturday, lateral raises ⇄ face pulls supersetted.

## Rest times — this is what keeps lifting under 60 minutes

| Work | Rest |
|------|------|
| Main 5/3/1 sets (Squat, Bench Press, Deadlift) | 2–3 minutes |
| Secondary barbell (speed squat, Bench Press 5×5, Overhead Press) | 2 minutes (speed squat 60–90 seconds) |
| Accessories, dips, core | 60–90 seconds |
| Supersets | 60–75 seconds after each pair |
| Explosive / plyometrics | full rest — never rushed |

**Target times (warm-up included, stair stepper extra):** Monday ~53 · Tuesday ~56 · Thursday ~47 · Friday ~37 · Saturday ~55 minutes. Running long? Rest discipline first; never cut the explosive work or the main lift.

## Warm-up (day-specific — non-optional)

Shape every day: **raise temperature (2–3 minutes easy row / bike / jumping jacks — not the stair stepper) → day-specific mobility → ramp into the first movement.**

| Session | Mobility | Ramp into |
|---------|----------|-----------|
| **Monday** (snatch + squat) | ankle rocks, deep-squat holds, wrist prep, band pull-aparts, overhead pass-throughs, hip openers | empty-bar snatch complex → skill weight |
| **Tuesday / Saturday** (plyometrics + bench) | band pull-aparts, arm circles, thoracic openers, cat-cow, 1×10–15 pushups | a few light medicine-ball throws into the plyometrics |
| **Thursday** (deadlift) | cat-cow, hip hinges, glute bridges, band good-mornings, hamstring floss | ramp sets: empty bar ×10 → 60 ×5 → then the week's set 1 |
| **Friday** (cleans + jumps) | ankle / hip / thoracic mobility, front-rack stretch, wrist prep, glute activation | pogos → tuck jumps → box jumps → empty-bar clean complex |

**Evening (~2 minutes, body already warm):** arm swings + band pull-aparts → 2× scapular pulls / dead hang → one light ramp set of each movement. *Cold-body fallback:* add 10 easy knee / incline pushups + wrist prep first.

## Evening Grease the Groove

Always submaximal, **every rep chest to bar**, 2–3 reps in reserve on pull, ~2 on push. 4–5 supersetted pull ⇄ push rounds, ~90 seconds between rounds, 15–20 minutes total.

**Grip by day:** **Pullup** (overhand) Monday / Thursday / Friday · **Chin-up** (underhand) Tuesday / Wednesday / Saturday.

**Retest max pullups fresh before week 1.** Table below assumes a max of **12** (working reps ≈ ½ max). Different max → week-3 reps = ½ max, weeks 1–2 = one rep less.

| Week | Pull full | Pull light (Thursday) | Push full | Push light (Tuesday, Thursday, Saturday) | Curls (Monday, Wednesday, Friday) |
|------|-----------|-----------------------|-----------|--------------------------------|-----------------------------------|
| **1** | 4×5 | 2×5 | 4×8 | 2×8 pushups | 12 kg kettlebell 2×15 |
| **2** | 5×5 | 2×5 | 4×10 | 2×10 pushups | 12 kg kettlebell 2×16 |
| **3** | 5×6 | 2×6 | 5×10 | 2×10 pushups | 12 kg kettlebell 2×17 |
| **4 deload** | 3×3 | 1×3 + dead hang | 3×6 | skip | 1×15 |

**Push full rotation** (one per evening, same sets × reps): kettlebell floor press **20 kg** / feet-elevated pushups **bodyweight** / kettlebell overhead triceps extension **16 kg**. Dips are left out — they're done at midday once a week (Saturday).

### What "light" means

| | Light pull (Thursday — evening after the heavy deadlift) | Light push (Tuesday, Saturday — after bench; Thursday — after Overhead Press) |
|---|---|---|
| **Volume** | Half the week's sets, same reps (see table) | Half the week's sets, same reps (see table) |
| **Effort** | Stop with **4+ reps in reserve** — nothing should feel like work | Stop with **~4 reps in reserve** |
| **Load / variation** | Bodyweight only, controlled (not explosive) chest-to-bar reps | **Bodyweight pushups only** — no dips, no triceps extensions, no kettlebell |
| **Finish** | 2× 20–30 seconds dead hang or scapular pulls | — |
| **Why** | Keeps the daily groove without draining grip / lats the deadlift just used | Blood flow + practice, zero extra triceps fatigue on top of the midday pressing |

If in doubt, do less — a light session exists to keep the habit, not to add training.
