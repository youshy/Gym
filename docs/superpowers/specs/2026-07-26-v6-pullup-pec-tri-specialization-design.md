# Workout Plan v6 — Pullup + Pec/Tri Specialization (design spec)

**Status:** design approved 2026-07-26, pending spec review before implementation.
**Relationship to v5:** v6 is **not a rewrite.** It is a *specialization layer* bolted onto the v5 athletic-power base. v5's structure — snatch/cleans/plyo over a 5/3/1 (5's PRO) base + easy Z2 running — stays fully intact. v6 adds a second daily session and modest chest/tri emphasis to the two existing press days.

---

## Goals (in priority order)

1. **Athletic power stays #1.** Nothing in v6 may compromise v5's explosive/Oly work. (User decision.)
2. **Drive the pullup up fast** via high-frequency, submaximal practice ("grease the groove"). Baseline: 6–10 strict reps.
3. **Add chest (pectorals) + triceps size** as a targeted bolt-on — via *frequency* (evening) + *intensity* (midday), without adding load to leg/power days.

**Time boxing:** run as an explicit **6–8 week specialization block** (two 4-week waves), then deload and return to lean base v5. This protects the no-rest-day system from silent fatigue accumulation.

---

## The core architecture — division of labor

| | Midday session (~11–12am) | Evening block (~15–20 min) |
|---|---|---|
| **What** | Full v5 main session | GtG antagonist **pull + push** |
| **Pull plane** | Horizontal (rows) — back balance | **Vertical (pullups)** — the priority |
| **Push role** | Chest/tri **intensity** (Tue/Sat bench + adds) | Chest/tri **frequency** (daily submax push) |
| **Effort** | As per v5 (5's PRO, explosive) | **Always submaximal — never to failure** |

**Why the add-on is evening, not morning:** the main session is at 11–12am. A morning add-on would sit ~3h before it and pre-fatigue the exact muscles used at midday — backwards for "power #1." Evening gives ~8h separation (a true second session), the body is already warm (short warm-up), and frequency is preserved. *(A cold-body morning warm-up protocol is retained only as a fallback if the block is ever done truly cold.)*

---

## The evening block (grease-the-groove pull/push)

- **Frequency:** ~6 working days/week + Sunday as a light mobility/scap day (or off).
- **Rule that governs everything:** *if it ever feels like a grind, it has failed its purpose.* Submaximal always — pullups at ~2–3 reps in reserve, push at ~2 RIR max.
- **At ~8 max pullups, working sets are ~4–5 reps** (roughly half of max), repeated.

**Warm-up (evening, body warm ~2 min; full cold-body version below for fallback):**
arm swings + band pull-aparts → 2× scap pulls / dead hang → one light ramp set of each movement.

*Cold-body fallback (~3–4 min):* add 10 easy knee/incline pushups + wrist prep before ramping.

**The work — 4–5 antagonist supersetted rounds, ~90s between rounds:**

| | Pull (priority) | Push (chest/tri frequency) |
|---|---|---|
| Sets | 4–5 × 4–5 strict pullups (submax) | 4–5 × 8–12, paired |
| Push rotation | — | KB floor press / feet-elevated or weighted pushups / KB overhead triceps ext / dips |
| Optional finisher (~2 min) | — | one KB curl or triceps set if time |

**Progression:** pullups — chase **weekly total reps**; when crisp, add reps/sets. Once 5×5 submax is easy → hang a light KB (weighted) *or* add reps. Push — reps first, then load (KB / feet elevation / weight).

**Per-day emphasis (deconfliction with the midday session):**

| Day | Pull | Push | Reason |
|---|---|---|---|
| Mon | full | full | upper fresh (squat day midday) |
| Tue | full | **light** | benched heavy midday |
| Wed | full | full | best add-on day (no midday lift) |
| Thu | **light** | full | spare grip/lats for the deadlift |
| Fri | full | full | upper fresh (cleans/legs midday) |
| Sat | full | **light** | benched (volume) midday |
| Sun | light mobility/scap only, or off | | biggest run day = built-in light day |

## Mesocycle waves (3 load + 1 deload, synced to 5/3/1)

The waves align to the existing 5/3/1 4-week cycle so the **whole system deloads in the same week** — lifts, runs, and the evening block together.

| Week | Pull / day | Push / day | Intent |
|---|---|---|---|
| **1** | 4 × 4 (16 reps) | 4 × 8 | re-anchor, crisp |
| **2** | 5 × 4 (20 reps) | 4 × 10 | add volume |
| **3** | 5 × 5 (25 reps) *or* add light KB | 5 × 10 / add load | peak |
| **4 — deload** | ~50%: 3 × 3, mobility-biased | 3 × 6 easy | recover with everything else |

**End of each wave:** retest max pullups *fresh* (warm, e.g. a weekend — not cold), reset working reps to ~half the new max, climb again. The 6–8 week block = two waves.

## Midday (main) session changes — only Tue + Sat touched

Vertical pulling leaves midday (owned by the evening block); horizontal pulling stays for back balance.

| Day (midday) | Keep (v5) | Add for chest/tri | Rotating compound |
|---|---|---|---|
| **Mon** | Snatch → Squat 5's PRO | — | RDL / lunge |
| **Tue** | plyo pushups → Bench 5's PRO → OHP | **Incline DB press 3×8–12** + **overhead triceps ext / skullcrusher 3×8–12** | **Dips** (DB rows dropped — pull covered) |
| **Wed** | — rest from lifting — | — | — |
| **Thu** | Deadlift 5's PRO | — | **Barbell rows** (horizontal pull stays) |
| **Fri** | Cleans + jumps → speed squat | — | — (cleans day) |
| **Sat** | plyo pushups → Bench volume 5×5 → OHP | **Weighted dips / incline 3×8–12** + **triceps pushdown 3×12–15** | Dips/incline (rear-delt flies optional) |
| **Sun** | — rest from lifting — | — | — |

- **Pullups removed** from midday Tue/Thu/Sat (absorbed by the evening block).
- **Face pulls + lateral raises stay daily** (shoulder health/target, unchanged from v5).
- **Volume check:** chest ≈ **14 direct hard sets/week** midday + evening frequency; triceps ≈ **6 direct** + heavy pressing + evening. Both comfortably in hypertrophy range, zero sets added to leg/power days.

## No-equipment backup (travel / hotel)

Same GtG philosophy, same 3+1 waves, zero gear. Mirrors the v4/v5 hotel-backup docs. Push is easy bodyweight; the **pull side is the real gap with no bar and no bands**, so it gets creative substitutes.

**Push (chest/tri) — handstand-pushup ladder + friends:**
pike pushup → feet-elevated pike → wall HSPU negatives → wall HSPU → deficit HSPU (books under hands). Pair with **diamond/close-grip pushups** (triceps) and **chair dips** (tri / lower pec).

**Pull (improvised horizontal rows):**
- **Inverted rows under a sturdy desk/table** (walk feet out to harden) — closest bar-free match to the pullup pattern.
- **Door-anchored towel rows** — towel over a closed, latched door; grip both ends; lean back and row.
- **Backpack gorilla / bent-over rows** — load a backpack with books/bottles.
- **Sliding floor lat pull-ins** — prone on a slick floor, towels under hands, pull the body forward (lat activation with nothing).

Same antagonist superset structure, same submaximal reps-in-reserve rule, same per-day light/full emphasis.

## Recovery / auto-regulation (this is now a two-a-day on a no-rest-day base)

- **Everything deloads together in week 4:** 5/3/1 deload + runs −40% + evening block to ~50%. Non-negotiable.
- **Time-boxed:** two 4-week waves (8 weeks), then strip to lean base v5 before re-running.
- **Knobs to pull, in order, if fatigue accumulates:**
  1. Evening block → **pull-only** (drop push first — protects the priority).
  2. Cut evening days 6 → 4.
  3. Then v5's existing knobs (Fri jump volume → Mon/Thu run distance → accessory sets → extra deload).
- **Red flags specific to v6:** elbow/shoulder tendon niggles (high press+pull frequency) → cut push load, add RIR; grip fatigue bleeding into Thu deadlift → make Thu evening pull lighter or skip; evening block disrupting sleep → move earlier / it's too hard.
