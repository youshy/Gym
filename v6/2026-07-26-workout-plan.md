# Workout Plan v6 — Pullup + Pec/Tri Specialization over the v5 Athletic-Power Base

**Goal:** Keep athletic power as the #1 driver, but bolt on two focused adaptations: **drive the strict pullup up fast** (high-frequency, submaximal practice) and **add chest + triceps size** — without stealing anything from the explosive work or the legs.

**What this is:** v6 **supersedes v5** and is fully standalone — you never need the v5 doc open beside it. It keeps v5's athletic-power engine entirely intact (snatch/cleans/plyo over a 5/3/1 "5's PRO" base + easy Z2 running) and folds the pullup + pec/tri specialization in as first-class parts of the week. The specialization runs as a **time-boxed 6–8 week block** (two 4-week waves), then you deload and return to the lean base before re-running it.

**Schedule:** 5 lift days (Mon, Tue, Thu, Fri, Sat) at **~11–12am** + a short **evening** pull/push block ~6 days/week + running 7 days/week. Rest from lifting: Wed, Sun (big run days).

**Calculator:** live barbell weights live in [`v6-calculator.html`](v6-calculator.html) — update TMs there as you go; don't hand-maintain numbers in this doc.

---

## Goals & Priority Order

1. **Athletic power stays #1.** Nothing here compromises the explosive/Oly work. v6 adds **zero** load to leg/power days (Mon, Fri).
2. **Pullups, fast** — from a 6–10 strict-rep baseline, via daily submaximal frequency ("grease the groove").
3. **Chest + triceps size** — as a targeted bolt-on, hit from two angles: *frequency* (evening) + *intensity* (midday press days).

**Time-boxing:** run this as an explicit **6–8 week block = two 4-week waves**, then deload and strip back to lean base before re-running. This protects a no-full-rest-day system from silently accumulating fatigue.

---

## Core Architecture — Division of Labor

Two sessions a day, each with a clear job:

| | **Midday (~11–12am)** — main session | **Evening (~15–20 min)** — GtG block |
|---|---|---|
| **What** | Full athletic-power session | Antagonist **pull + push** supersets |
| **Pull plane** | Horizontal (rows) — back balance | **Vertical (pullups)** — the priority |
| **Push role** | Chest/tri **intensity** (Tue/Sat bench + adds) | Chest/tri **frequency** (daily submax push) |
| **Effort** | 5's PRO + explosive (see engine) | **Always submaximal — never to failure** |

**Why the add-on is evening, not morning:** the main session is at 11–12am. A morning add-on would land ~3h before it and pre-fatigue the exact muscles you press and pull with at midday — backwards for "power #1." Evening gives ~8h of separation (a genuine second session, not interference), your body is already warm so the warm-up is short, and the pullup still gets its daily frequency. *(A fuller cold-body warm-up is kept as a fallback for the rare times you do it truly cold — see the evening block.)*

## The Week

Three layers per day — midday main, evening GtG, run:

| Day | Midday (~11–12) main | Evening GtG (~15–20 min) | Run |
|-----|----------------------|--------------------------|-----|
| **Mon** | **Snatch — skill** (light ~15 min) → **Squat** 5's PRO → RDL/lunge → laterals + face pulls → ab-wheel | **Pull full + Push full** (upper's fresh) | 3km flat |
| **Tue** | **Upper plyo** → **Bench** 5's PRO → OHP → **incline DB + triceps ext** → dips → laterals + face pulls → hanging leg raises | **Pull full + Push light** (benched midday) | 4–5km |
| **Wed** | — rest from lifting — | **Pull full + Push full** (best add-on day) | 8–12km easy |
| **Thu** | (opt. light high-pulls) → **Deadlift** 5's PRO → barbell rows → laterals + face pulls → suitcase carry | **Pull light + Push full** (spare grip/lats) | 3km flat |
| **Fri** | **Cleans (loaded) + lower-body jumps** → light squat (speed) → laterals + face pulls | **Pull full + Push full** (upper's fresh) | 4–5km |
| **Sat** | **Upper plyo** → **Bench volume** 5×5 → OHP → **incline/dips + pushdown** → laterals + face pulls → side plank | **Pull full + Push light** (benched midday) | 4–5km |
| **Sun** | — rest from lifting — | **Optional** (light mobility/scap, or off) | 10–15km long slow |

**Every midday lift day runs in this order:** day-specific warm-up → **explosive opener (while fresh)** → main lift (5's PRO) → chest/tri or pull adds → laterals + face pulls → core finisher → run.

**Placement logic (carried from the athletic base):**
- Snatch is light skill, so it sits before a heavy squat without denting it — and primes the CNS.
- **All high-impact leg/pull power is concentrated on Friday** (cleans + jumps), deliberately away from heavy squat (Mon) and heavy deadlift (Thu). Saturday buffers Friday's jumps from Sunday's long run.
- Upper plyos live on both press days because they cost your legs nothing.
- **Vertical pulling (pullups) moved entirely to the evening**; horizontal pulling (rows) stays at midday so the back is still trained in both planes.

**Rules:**
- Heavy leg days (Mon, Thu) get the **shortest, flattest 3km** — first runs to cut if recovery slips.
- All runs easy/conversational Z2. No hard running on lift days.
- Explosive work is **low-volume, max-intent, full-rest — never a grind.** If bar speed or jump height drops, that set was your last.

## The Midday Session (the athletic-power base + v6 changes)

### Warm-ups (day-specific — non-optional)

General shape: **raise temp (2–3 min easy row/bike/jacks) → day-specific mobility → ramp into the first explosive/main movement.** Explosive days need a thorough ramp — you're asking joints to move fast under load.

- **Mon (snatch + squat):** temp raise → ankle rocks, deep-squat holds, wrist prep, band pull-aparts, overhead pass-throughs, hip openers → **empty-bar snatch complex** (muscle snatch → snatch balance → overhead squat) building to skill weight.
- **Tue (upper plyo + bench):** temp raise → band pull-aparts, arm circles, thoracic openers, cat-cow, **1×10–15 pushups (primer)** → a few light med-ball throws to ramp into the plyo.
- **Thu (deadlift):** temp raise → cat-cow, hip hinges, glute bridges, band good-mornings, hamstring floss → progressively heavier ramp sets to first working weight.
- **Fri (cleans + jumps — most thorough):** temp raise → ankle/hip/thoracic mobility, front-rack stretch, wrist prep, glute activation → **jump ramp: pogos → tuck jumps → box jumps** → **empty-bar clean complex** building to working weight.
- **Sat (upper plyo + bench volume):** same shape as Tue.

### Explosive work (the athletic priority — unchanged)

All low-volume, maximal intent, full recovery. **Quality is the cap — stop while crisp.**

- **Snatch — skill (Mon):** ~15 min. Empty-to-light complex: muscle snatch → snatch balance → hang snatch → full snatch. Working feel **~40–50kg**, heavier only when every position is crisp. **No load target** — this is motor-skill practice.
- **Cleans — loaded (Fri):** hang/power clean, **5–6 × 2–3.** Build to **~50–60kg** (~70–85% of a ~70kg best). Sample ramp: 40×3 → 45×3 → 50×2 → 55×2 → 60×2. **Governed by bar speed, not %** — the moment the bar slows, that's your top set.
- **Lower-body jumps (Fri):** box/broad jumps, short bounds, **3–5 × 3–5.** Land soft, full recovery. **Depth jumps only when tendons feel fresh.**
- **Upper-body plyos (Tue + Sat):** med-ball chest pass + overhead throw, or clap/plyo pushups, or slams. **3–5 × 3–5**, explosive, full rest. Zero leg cost — that's why they live on press days.

### v6 chest/tri additions — only Tue + Sat touched

After the main lift on the two press days, add targeted hypertrophy work (compound-first, **3×8–12** unless noted):

| Day | Add for chest/tri | Rotating compound |
|-----|-------------------|-------------------|
| **Tue** | **Incline DB press 3×8–12** + **overhead triceps extension / skull-crusher 3×8–12** | **Dips** (DB rows dropped — vertical pull is covered in the evening) |
| **Sat** | **Weighted dips or incline 3×8–12** + **triceps pushdown 3×12–15** | Dips/incline (rear-delt flies optional if time) |

This lands chest at **~14 direct hard sets/week** midday + evening frequency, and triceps at **~6 direct** + heavy pressing + evening — both comfortably in hypertrophy range, with **zero sets added to leg/power days.**

### Pull & shoulder work at midday
- **Barbell rows stay on Thu** (horizontal pull for back balance) — pullups are handled entirely in the evening.
- **Every lift day (shoulder insurance):** lateral raises 3×12–15, face pulls 3×15.
- **Rotating compound — pick ONE per day:** Mon RDLs / walking lunges · Tue dips · Thu barbell rows · Sat dips / rear-delt flies. *(Fri has none — cleans + jumps + speed squat are the day.)*

### Core (the Oly lifts already hammer the trunk)

| Day | Movement | Prescription | Function |
|-----|----------|--------------|----------|
| Mon | Ab-wheel rollout | 3 sets to controlled failure | Anti-extension |
| Tue | Hanging leg raises | 3×10–15 | Flexion |
| Thu | Suitcase carry | 3×20m/side | Anti-lateral flexion + grip |
| Fri | — (cleans cover it) | — | — |
| Sat | Side plank | 3×30–45s/side | Anti-lateral flexion |

**Deload week:** 1 set each, or skip.

## The Evening Block — Grease-the-Groove Pull/Push

15–20 min, ~6 working days/week (Sunday optional). **The rule that governs everything: always submaximal — if it ever feels like a grind, it has failed its purpose.** Greasing the groove drives the pullup up through frequent *quality* practice, not fatigue. At ~8 max pullups, your working sets are **~4–5 reps** (roughly half of max), repeated.

**Warm-up (evening, body already warm — ~2 min):** arm swings + band pull-aparts → 2× scap pulls / dead hang → one light ramp set of each movement.
**Cold-body fallback (~3–4 min, only if done truly cold):** add 10 easy knee/incline pushups + wrist prep before ramping.

**The work — 4–5 antagonist supersetted rounds, ~90s between rounds:**

| | Pull (priority) | Push (chest/tri frequency) |
|---|---|---|
| Sets | 4–5 × 4–5 strict pullups (submax) | 4–5 × 8–12, paired |
| Push rotation | — | KB floor press / feet-elevated or weighted pushups / KB overhead triceps ext / dips |
| Optional finisher (~2 min) | — | one KB curl or triceps set if time |

**Progression:** pullups — chase **weekly total reps**; when crisp, add reps/sets. Once 5×5 submax is easy → hang a light KB (weighted) *or* add reps. Push — reps first, then load (KB / feet elevation / weight). Keep pull at **2–3 reps in reserve** always; push can approach ~2 RIR but stays clean.

**Per-day emphasis (deconfliction with the midday session):**

| Day | Pull | Push | Reason |
|-----|------|------|--------|
| Mon | full | full | upper fresh (squat midday) |
| Tue | full | **light** | benched heavy midday |
| Wed | full | full | best add-on day (no midday lift) |
| Thu | **light** | full | spare grip/lats for the deadlift |
| Fri | full | full | upper fresh (cleans/legs midday) |
| Sat | full | **light** | benched (volume) midday |
| Sun | **optional** — light mobility/scap, or off | | biggest run day = built-in light day |

## Mesocycle Waves (3 load + 1 deload, synced to 5/3/1)

The evening waves align to the 5/3/1 4-week cycle so the **whole system deloads in the same week** — lifts, runs, and the evening block together. Nothing accumulates in a silo.

| Week | Pull / day | Push / day | Intent |
|------|-----------|-----------|--------|
| **1** | 4 × 4 (16 reps) | 4 × 8 | re-anchor, crisp |
| **2** | 5 × 4 (20 reps) | 4 × 10 | add volume |
| **3** | 5 × 5 (25 reps) *or* add light KB | 5 × 10 / add load | peak |
| **4 — deload** | ~50%: 3 × 3, mobility-biased | 3 × 6 easy | recover with everything else |

**End of each wave:** retest max pullups **fresh** (warm — e.g. a weekend, not a cold morning), reset working reps to ~half the new max, climb again. The 6–8 week specialization = **two of these waves**, then return to lean base.

## Progression Engine — 5's PRO

Everything is driven by **Training Max (TM) = 90% of estimated 1RM** for each barbell lift. **Anti-imaginary-numbers rules:** TM is derived from a set you *actually completed* (est. 1RM = weight × (1 + reps/30), Epley), and every working weight rounds **down** to a loadable plate. The calculator does all of this — see [`v6-calculator.html`](v6-calculator.html).

### Heavy days — Mon squat, Tue bench, Thu deadlift (5's PRO)

Every top set is a clean **5 reps** — no AMRAP. This removes the max-effort grind, leaving CNS for the explosive work; strength still climbs via TM increases.

| Week | Set 1 | Set 2 | Set 3 (×5) |
|------|-------|-------|------------|
| **1** | 65% ×5 | 75% ×5 | **85% ×5** |
| **2** | 70% ×5 | 80% ×5 | **90% ×5** |
| **3** | 75% ×5 | 85% ×5 | **95% ×5** |
| **4 (deload)** | 40% ×5 | 50% ×5 | 60% ×5 |

The 90%-TM buffer means even 95%×5 is only ~85% of true 1RM — hard, honest, not a grind.

### Starting TMs (derived 2026-07-20, carried into v6)

| Lift | Your set | Est. 1RM | **TM** | Note |
|------|----------|----------|--------|------|
| **Squat** | 90×8 (+3 RIR ≈ 90×11) | ~123 | **110** | Slightly bold; 5's PRO buffer absorbs it |
| **Bench** | 80×4 | ~91 | **80** | Honest |
| **Deadlift** | 100×8 (belt) | ~127 | **105** | ⚠️ Deliberately capped low for your back |

**Deadlift caution:** top set never exceeds ~97.5 vs your 100×8. Position and a pain-free back are the goal; load is secondary. Belt on, brace hard, stop the instant the back talks. Only raise this TM after a full symptom-free cycle.

### Volume / secondary work
- **Fri light squat (speed):** ~65% TM (**~70kg**), 5×3 fast — priming reps after cleans+jumps, never a grind.
- **Sat bench volume:** 5×5 @ ~65% TM (**~52.5kg**). Bump to 55 when it flies.
- **OHP (Tue + Sat):** owned-weight, no %. Start **30kg, 5×10.** When all 50 reps move fast and the last set isn't grindy → 32.5kg.

### TM progression (the anti-nightmare knob)
- +2.5kg upper / +5kg lower per **cycle** — but bump squat/DL **every *other* cycle.** Slower is the point.
- If a top 5 turns into a grind two cycles running, **reset that lift's TM to 85%** of current and re-climb.

## Recovery / Auto-Regulation (this is now a two-a-day on a no-full-rest-day base)

- **Everything deloads together in week 4:** 5/3/1 deload + runs −40% + evening block to ~50% (the wave-table deload row). Non-negotiable — it's what makes the two-a-day survivable.
- **Time-boxed:** two 4-week waves (8 weeks) of this specialization, then strip back to lean base before re-running.
- **Knobs to pull, in order, if fatigue accumulates:**
  1. Evening block → **pull-only** (drop push first — protects the pullup, the priority).
  2. Cut evening days 6 → 4.
  3. Then the base knobs: Fri jump volume → Mon/Thu run distance → accessory sets → an extra deload.
- **Red flags specific to v6:** elbow/shoulder tendon niggles (high press+pull frequency) → cut push load, add RIR; grip fatigue bleeding into Thu deadlift → make Thu evening pull lighter or skip it; evening block disrupting sleep → move it earlier / it's too hard (must stay submaximal).
- **The back is the canary:** if deadlift or cleans provoke it, cap load and drop TM before pushing on.
- **The one rule that holds it all together:** *if the evening block ever feels like a grind, it has failed its purpose.* Submaximal always.
